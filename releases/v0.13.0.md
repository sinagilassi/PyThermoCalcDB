# 🚀 v0.13.0 Release Notes

## ✨ Features

### 🧪 Molecular Weight Calculation

- Added molecular weight calculation module with support for complex chemical formulas
- New functions: `calc_molecular_weight()` and `calc_MW()`
- Features:
  - 🔢 Calculate molecular weights for compounds and ions
  - 💧 Support for hydrated salts (e.g., `CuSO4*5H2O`)
  - ⚛️ Optional electron mass inclusion for charged species
  - 🎯 Configurable decimal precision
  - 🔗 Handles ionic species notation (e.g., `Fe{3+}`, `OH{-}`)

### 📝 Example Usage

```python
from pythermocalcdb.thermo.molecular_weight import calc_MW

compounds = ["Fe(OH)3", "Ca3(PO4)2", "CuSO4*5H2O", "H2O"]
for compound in compounds:
    mw = calc_MW(compound, include_electron_mass=True, decimal_digits=3)
    print(f"Molecular weight of {compound}: {mw}")
```
